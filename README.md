# \# E-Commerce API

# 

# A backend e-commerce project built using \*\*ASP.NET Core Web API\*\* and \*\*Entity Framework Core\*\*.

# 

# \## Overview

# 

# This project provides backend functionality for an e-commerce application, including product management, user authentication, shopping basket management, and order processing.

# 

# The main goal of this project is to apply clean code principles, layered architecture, and modern .NET development practices.

# 

# \## Technologies Used

# 

# \- C#

# \- ASP.NET Core Web API

# \- Entity Framework Core

# \- SQL Server

# \- ASP.NET Core Identity

# \- JWT Authentication

# \- Redis

# \- AutoMapper

# \- Swagger / OpenAPI

# \- Postman

# 

# \## Architecture

# 

# The solution is organized into separate layers to improve maintainability and separation of concerns.

# 

# \- \*\*Domain:\*\* Core entities and business models.

# \- \*\*Services:\*\* Application services and business logic.

# \- \*\*Persistence:\*\* Database context, repositories, and data access.

# \- \*\*API:\*\* Controllers, middleware, dependency injection, and HTTP endpoints.

# 

# \## Features

# 

# \- Product and category management.

# \- User registration and authentication.

# \- JWT-based authentication.

# \- Shopping basket management using Redis.

# \- Order creation and retrieval.

# \- Delivery method management.

# \- Entity Framework Core migrations.

# \- Centralized exception handling and API validation.

# \- API documentation using Swagger.

# \- API testing using Postman.

# 

# \## Payment Integration

# 

# Stripe payment integration is currently a work in progress.

# 

# \## API Testing

# 

# Postman can be used to test the available API endpoints.

# 

# \## Security

# 

# Sensitive configuration values, connection strings, and secret keys are excluded from version control.

# 

# \## Project Status

# 

# This project is under development. Features and documentation may change as development continues.
